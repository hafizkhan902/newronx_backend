================================================================================
                        📊 TEAM PERFORMANCE API - COMPREHENSIVE GUIDE
================================================================================

🎯 OVERVIEW
-----------
Complete performance analytics system for StudentMate teams with:
- Team-wide performance metrics and insights
- Individual member performance analysis
- Historical trends and pattern recognition
- Automated alerts and recommendations
- Premium access control with trial support
- Advanced calculation algorithms with weighted scoring

Base URL: /api/performance
Access Level: Premium Feature (Idea Authors Only)
Rate Limits: 50 req/hour (Premium), 5 req/hour (Trial)

================================================================================
🔐 AUTHENTICATION & ACCESS CONTROL
================================================================================

All endpoints require:
1. JWT Authentication (Bearer token)
2. Premium subscription or active trial
3. Idea/Team ownership verification (for team-specific endpoints)

Headers Required:
```
Authorization: Bearer {your_jwt_token}
Content-Type: application/json
```

Access Restrictions:
- Only idea authors can access team performance data
- Individual performance data is only visible to team leaders
- Alerts are only visible to alert owners
- Rate limiting based on subscription tier

2️⃣ TRIGGER PERFORMANCE RECALCULATION
-------------------------------------
POST /api/performance/{ideaId}/recalculate

Force recalculation of team performance metrics.

Request Body:
```json
{
  "force": true,        // Optional: override recent calculation check
  "timeRange": "30d"    // Optional: specific time range to recalculate
}
```

Response:
```json
{
  "success": true,
  "message": "Performance recalculation triggered",
  "data": {
    "calculationId": "calc_1726052400123_abc789def",
    "estimatedCompletionTime": "2025-09-11T10:35:00.000Z",
    "status": "processing",
    "timeRange": "30d",
    "forced": true
  }
}
```

📊 PERFORMANCE CALCULATION METHODOLOGY
================================================================================

🎯 SCORING SYSTEM
-----------------

Individual Performance Score (0-5.0):
- Tasks (40%): Completion rate, on-time delivery, priority handling
- Communication (25%): Response time, activity level, message quality
- Collaboration (20%): Team interaction, knowledge sharing, engagement
- Contribution (15%): File sharing, documentation, variety of contributions

Team Performance Score (0-100%):
- Task Completion (40%): Overall completion rate and quality
- Average Quality (30%): Average individual performance scores
- Collaboration (20%): Team interaction and knowledge sharing
- Velocity (10%): Task completion speed and efficiency

🏆 GRADING SCALE
----------------
- A+ (4.5-5.0): Exceptional performance
- A  (4.0-4.4): Excellent performance
- A- (3.5-3.9): Very good performance
- B+ (3.0-3.4): Good performance
- B  (2.5-2.9): Above average performance
- B- (2.0-2.4): Average performance
- C+ (1.5-1.9): Below average performance
- C  (1.0-1.4): Poor performance
- C- (0.5-0.9): Very poor performance
- D  (0.0-0.4): Failing performance

📈 TREND ANALYSIS
-----------------
- Up: >5% improvement over comparison period
- Stable: -5% to +5% change over comparison period
- Down: >5% decline over comparison period

🚨 ALERT THRESHOLDS
-------------------
- Performance Drop: Individual score < 3.0 or >20% decline
- Deadline Risk: >3 overdue tasks or <60% completion rate
- Low Engagement: <3.0 collaboration score or <2 messages/day
- Team Milestone: >90% task completion or >4.0 average score

Basic Dashboard Request:
```javascript
const response = await fetch('/api/performance/68b310dec1769ad5a4a420f3/dashboard', {
  headers: {
    'Authorization': `Bearer ${token}`,
```

```javascript

    'Content-Type': 'application/json'
```

```javascript
const response = await fetch('/api/performance/68b310dec1769ad5a4a420f3/export?format=csv&timeRange=30d', {
  headers: { 'Authorization': `Bearer ${token}` }
});
```
